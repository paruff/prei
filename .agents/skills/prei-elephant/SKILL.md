# prei Elephant Skill — project context for EGM

## When to load
- Drafting or reviewing intent, spec, plan or a technical design.

## Read order
| File | Why |
|---|---|
| `VISION.md` | users, journey, principles, non-goals |
| `intent.md`, `spec.md`, `plan.md` | active outcome, requirements (FR/AC IDs), goals and rows |
| `DESIGN.md` | UI design system only |
| `docs/ARCHITECTURE.md` | layer rules |
| `docs/CHANGE_IMPACT_MAP.md` | co-changes |
| `docs/KNOWN_LIMITATIONS.md` | active limits (LIMIT-n) |
| `docs/designs/SITEMAP.md` | existing technical designs |
| `core/*/README.md` | per-directory contracts |
| `features/<slug>/` | archived intent/spec/plan of past work (read-only) |
