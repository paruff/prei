# Design System — prei

The design system (tokens, typography, layout, components, do's and don'ts) is documented in
[DESIGN.md](https://github.com/paruff/prei/blob/main/DESIGN.md) at the repository root, in the [DESIGN.md format](https://github.com/google-labs-code/design.md).

- Token values: `static/css/tokens.css` (the browser's source of truth; DESIGN.md mirrors it)
- Component styles: `static/css/base.css`, `static/css/pipeline.css`
- Reusable partials: `templates/components/`
- Where components appear in the UI: [UI Patterns](../reference/ui-patterns.md)
