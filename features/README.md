# Feature Archive

Each subdirectory archives the intent, spec and plan of a completed feature or goal set.
The active documents live at the repo root: [intent.md](../intent.md), [spec.md](../spec.md),
[plan.md](../plan.md) (workflow: [AGENTS.md](../AGENTS.md)). Status lives on the board, not here.

## Convention

When a goal set ships, its root `intent.md`, `spec.md` and `plan.md` are archived into
`features/<slug>/`. Technical designs are living documents and stay in
[docs/designs/](../docs/designs/); the archive links to them.

| Folder | Layout |
|---|---|
| `functioning-prei/` | `intent.md`, `spec.md`, `plan.md` (current convention) |
| `top01-phase-a/`, `top01-phase-b/`, `gitops-phase3-hardening/` | older `specification.md`, `design.md`, `tasks.json`; kept as is |

Older discovery features are in [docs/feature/](../docs/feature/).
